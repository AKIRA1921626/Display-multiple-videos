# Display-multiple-videos

複数の動画を画面上に指定した位置に配置することで、比較動画などを作りやすくしたカスタムオブジェクト。

カスタムオブジェクトなので、「メディアオブジェクト→複数画面表示」の所に表示されます。

無印の物は、自分で3割ぐらい書いてあとはGeminiに書いてもらい、v2はそれをそのままAntigravityに渡して作ってもらいました。  
なので、v2の方が機能が多くて使いやすいので、ほぼ（完全に？）上位互換です。  

v3はv2の機能を、特定の目的のために変更したものとなります。  

v4は機能を追加したが、その分動画を6個までしか指定できなくなったものとなります。  

どれが使いやすいかは、状況によるため、v2以降の物は上位互換とはいえない変更となります。  

**このスクリプトでは秒数指定で動画と完全に同じ秒数を指定しても、一瞬だけ前後の動画が移ることがありますので、ご注意ください。**  
この問題の発生理由と思しき製作者さんの投稿を見かけた。  
https://x.com/__kenkun/status/2080905063749554186  

二次配布可、改変可、クレジット不要
